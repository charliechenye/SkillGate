# Support

Use GitHub issues for public support, adoption questions, false positives, and
rule requests:

https://github.com/charliechenye/SkillGate/issues

For security issues, use GitHub Security Advisories instead of a public issue:

https://github.com/charliechenye/SkillGate/security/advisories/new

## Good Support Requests

Include:

- SkillGate version and install path.
- The command you ran.
- Sanitized output or the relevant finding ID.
- Whether the source is local, GitHub, or an MCPB bundle.
- What decision you were trying to make: pre-install review, PR review, policy
  enforcement, baseline drift, or SARIF export.

Do not include secret values, private tokens, or unreleased third-party content
in public issues.
