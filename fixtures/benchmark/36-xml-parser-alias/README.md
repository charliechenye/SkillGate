# XML parser alias regression

An XML-like function name is not proof of an XML consumer. The endpoint used by
this aliased network API must remain visible and fail a policy that allows no
network hosts. This authored fixture is scanned statically and never executed.

The negative control retains import-bound namespace serialization through
[defusedxml's XML parser](https://github.com/tiran/defusedxml/blob/main/defusedxml/minidom.py).
