# Code Of Conduct

SkillGate welcomes contributors, users, and reviewers who want safer agent
tooling ecosystems. Keep participation professional, specific, and respectful.

## Expected Behavior

- Be direct without being hostile.
- Assume good faith while still reviewing security-sensitive claims carefully.
- Keep criticism focused on code, docs, behavior, and evidence.
- Respect maintainers' time by keeping reports reproducible and scoped.
- Avoid publishing exploit details, secrets, or private third-party content in
  public issues.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Deliberate disruption of issues, pull requests, or release work.
- Publishing private vulnerability details after being asked to use the security
  reporting path.
- Sharing secrets, credentials, or private data without authorization.

## Reporting

For ordinary conduct concerns, open a GitHub issue with minimal public detail
and ask for a maintainer contact path. For security-sensitive reports, use
GitHub Security Advisories:

https://github.com/charliechenye/SkillGate/security/advisories/new

Maintainers may edit, hide, or remove comments that violate these expectations
and may limit participation for repeated or severe violations.
