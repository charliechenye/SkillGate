# SkillGate v0.1.4

## GitHub skill review fixes

GitHub reviews now validate skills against their original directory names,
avoiding false `SKILL004` findings caused by the temporary scan directory.
Bare product names such as `Next.js` and `skills.sh` no longer cause missing
script errors unless they refer to an actual repository file. Explicit missing
relative script paths still produce errors.

Sparse scans now include bundled Markdown and supported helper scripts inside
discovered skill directories, even when `SKILL.md` does not link to them.
File-count, byte, subtree, and excluded-path limits still apply, and skipped
files remain visible in the source manifest. Reviewed content is never executed.

## More static review evidence

- MCP Apps review inventories declared UI resources, assets, origins,
  permissions, tools, and host bridge markers without rendering UI or fetching
  declared external URLs.
- MCP Tasks inventory records explicitly declared task capabilities and
  lifecycle methods without starting servers or executing tasks.
- `skillgate skills validate SKILL.zip` validates packaged Agent Skills through
  the bounded archive safety layer.

Review Packet schema version `2`, existing rule IDs, and advisory defaults
remain unchanged. These signals describe observed capability surfaces; they
do not prove an artifact is safe or that static coverage is complete.

## Dependency and release maintenance

The development and release toolchain now locks `urllib3` to `2.8.0` and
`cryptography` to `50.0.2`, fixing four dependency security advisories. These
packages are not added to SkillGate's runtime dependencies.

Python, npx, and GitHub Action examples share the moving `v0` channel. The
release process validates versioned assets and installs before promoting `v0`
with an annotated noreply tag and an explicit push lease.

## Upgrade

Install the versioned GitHub source:

```bash
python -m pip install --upgrade "git+https://github.com/charliechenye/SkillGate.git@v0.1.4"
skillgate --version
skillgate review preinstall SOURCE --json-output skillgate-review.json
```

Use the checksummed standalone binaries through the Node wrapper:

```bash
SKILLGATE_VERSION=v0.1.4 npx --yes --allow-git=root github:charliechenye/SkillGate#v0.1.4 -- --version
```

The per-command `--allow-git=root` option is required with npm 12, which
[disables Git dependencies by default](https://docs.npmjs.com/cli/install/#allow-git).
It allows the requested root Git package without changing global npm settings.

Use `v0` to follow compatible releases, or pin the full release commit SHA for
immutable source and Action installs. PyPI and npm publication remain deferred.
Agent Plugins, MCP Skills, and semantic CLI exposure remain planned work.
