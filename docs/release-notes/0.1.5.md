# SkillGate v0.1.5: Explicit Review Coverage

## Explicit review coverage

Pre-install packets now distinguish `complete`, `incomplete`, `empty`, and
`unsupported` static coverage. Unreviewed files, MCPB entry points, and declared
MCP Apps gaps remain visible even when there are zero findings. Markdown shows
the coverage status, skipped paths, and zero counts.

Use the opt-in coverage gate independently of the finding threshold:

```bash
skillgate review preinstall SOURCE --require-complete --fail-on high \
  --output review.md --json-output review.json
```

Exit `0` means the requested gates passed, `1` means a gate rejected the input
while retaining its packet, and `2` means processing failed. The default stays
advisory. `complete` describes supported static scope; it does not prove safety.
Unscanned files outside standard exclusions still count as coverage gaps,
including license and package metadata. Review Packet stays at schema version
`2`, and older packets without coverage remain valid.

## Consistent skill review

Local directory pre-install reviews now include the same bundled Markdown and
supported scripts as GitHub reviews, including unlinked files. Ordinary scanner,
policy, inventory, and baseline discovery retain their existing behavior.

Script references match complete filename extensions: an example
`evals/evals.json` no longer becomes a missing `evals/evals.js` download target.
Real missing scripts still produce an error with source evidence.

## Public acceptance evidence

Ten pinned public skill samples record source identity, license and file
digests, skipped paths, validation results, and selected static evidence. The
explicit network evaluator checks repeatability and local/GitHub parity on
downloaded supported input without executing or vendoring upstream code.

The [acceptance report](https://github.com/charliechenye/SkillGate/blob/v0.1.5/docs/public-scan-reports/pinned-skills-acceptance.md)
records known noise, including collection operations, numeric comparisons, and
XML namespace URLs. Ten samples from two publishers do not support broad
accuracy claims. Independent human adjudication and maintainer pilots remain
pending; this release improves coverage accounting rather than retuning rules.

## Upgrade

```bash
python -m pip install --upgrade "git+https://github.com/charliechenye/SkillGate.git@v0.1.5"
skillgate --version
```

For checksummed standalone binaries through the Node wrapper:

```bash
SKILLGATE_VERSION=v0.1.5 npx --yes --allow-git=root github:charliechenye/SkillGate#v0.1.5 -- --version
```

Use `v0` to follow compatible releases, or pin the full release commit SHA for
immutable source and Action installs. PyPI and npm publication remain deferred.
Agent Plugins, MCP Skills, and the semantic CLI remain planned work.

## Known output-directory limitation

In `v0.1.5`, nested Markdown and JSON output directories for `review summary`
must exist before invocation. The documented GitHub Action examples write to
the repository root and work without preparation. If using a directory such as
`test-outputs`, create it first, for example with `mkdir -p test-outputs`.
Automatic summary directory creation is fixed on the development branch and
will ship in a later release.
